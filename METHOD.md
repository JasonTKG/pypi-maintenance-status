# Method

Generated by a deterministic script, with no manual edits and no model-written text. Every value is fetched from a
public source at build time; page text is a fixed template filled with those values.

1. Take the top 1000 PyPI projects by downloads over the last 30 days (https://hugovk.github.io/top-pypi-packages/top-pypi-packages-30-days.min.json).
2. For each, read all versions from deps.dev (`/v3/systems/pypi/packages/<name>`): the latest publish date of any
   release (pre-releases included), the latest stable release, and the number of releases in the past 365 days.
3. Read the latest stable version from the PyPI JSON API (`/pypi/<name>/<version>/json`) for the classifier
   `Development Status :: 7 - Inactive`.
4. Read that version on deps.dev (`.../versions/<v>`) for its source repository (relation `SOURCE_REPO`, GitHub only).
   If deps.dev has none, use the first github.com link in the package's own metadata (project URLs, then home page).
5. Read the repository's deps.dev project record for the OpenSSF Scorecard "Maintained" check (0–10, with its date), stars
   and open issues. Read the GitHub REST API for `archived` and `pushed_at`.
6. Status, first match wins:
   - **archived**: the GitHub repository is archived (unless the package released after the repository's last push,
     which means development moved; then the release-age rules apply)
   - **declared inactive**: the latest release carries the Inactive classifier
   - **active**: last release (of any kind) within 365 days
   - **slowing**: last release within 730 days
   - **stale**: older than that
   - **unknown**: no release date available

Limitations:
- Release dates are a proxy. A finished library can release rarely and still be well maintained.
- Repositories outside GitHub are not checked for archiving.
- Scorecard results lag, sometimes by months.
- A package can be archived on GitHub but continued under a new name or fork; this dataset does not follow renames.
- Deprecation notices written in a README or in the docs, and yanked releases, are not checked.
